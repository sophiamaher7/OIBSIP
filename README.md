# OIBSIP
Oasis Infobyte Internship Projects – Data Analytics

> **Oasis Infobyte Data Analytics Internship | Python & Data Analysis**

This repository contains the projects I completed during my **Data Analytics Internship with Oasis Infobyte (OIBSIP)**.

The projects focus on applying Python and data analytics techniques to practical datasets, covering different stages of the analytical workflow — from data cleaning and exploratory analysis to customer behaviour analysis and machine learning-based segmentation.

---

## 📂 Projects

### 1. 📊 Retail Sales Exploratory Data Analysis

An exploratory analysis of retail sales data designed to identify patterns, trends, and relationships within the dataset.

The analysis includes:

* Data inspection
* Data quality assessment
* Missing-value analysis
* Duplicate detection
* Monthly and quarterly sales trends
* Demographic analysis
* Product and category performance
* Revenue analysis
* Data visualisation

**Tools:** Python, pandas, Matplotlib, Seaborn, Jupyter Notebook

---

### 2. 🧹 Financial Data Cleaning

A data-cleaning project focused on preparing financial data for reliable downstream analysis.

The project covers:

* Data inspection
* Data quality assessment
* Missing-value handling
* Duplicate detection
* Data-type validation
* Identification of inconsistent or invalid records
* Data cleaning and preparation

**Tools:** Python, pandas, Jupyter Notebook
---

### 3. 👥 Customer Segmentation Analysis

A customer analytics project using the **Online Retail II / Online Retail transaction data** to identify groups of customers with similar purchasing behaviour.

The project applies **RFM analysis** and **K-Means clustering** to transform transaction-level data into customer-level behavioural segments.

The workflow includes:

* Data quality assessment
* Data cleaning
* Transaction-value calculation
* Customer-level aggregation
* RFM analysis
* Recency, Frequency and Monetary Value
* Average Purchase Value
* Historical Customer Lifetime Value
* Distribution analysis
* Log transformation
* Feature standardisation
* Elbow Method
* K-Means clustering
* Cluster profiling
* Customer-segment recommendations

The analysis resulted in **four customer segments** with different levels of purchasing activity, engagement, and historical customer value.

**Tools:** Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Jupyter Notebook
